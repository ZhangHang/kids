## 怎么使用

遇到值得记住的事情，就在当月记录里写几句：发生了什么、孩子怎么说、我们怎么理解。两人一起参加的活动只记一次，分别写她们的反应。

月底分别回顾两人的兴趣、变化和需要，给每人留下最多两个近期关注点，并想一想父母自己的做法要怎样调整。不要求每日打卡，也不要求每个月覆盖所有成长领域。

仓库使用简体中文和简单的 Markdown 文件。共享资源、个人档案和实际经历相互链接；学校年级、教材、兴趣与能力等待家长确认后再补充。

## 第一个主题：认识真实世界

从纪录片、真人实验和日常事物开始，重视观察、提问和完整的解释过程。观看偏好普通话；家长可以自行寻找中文音频，片源是否已核实不影响内容入选。《流言终结者》是已接受的主要候选。

片单是第一份资源，仓库也会随着孩子的生活，逐步加入阅读、运动、艺术、朋友、家务、学校和出行等内容。实际体验过后，再根据她们各自的反应调整。
