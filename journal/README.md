# 成长记录

[返回首页](../README.md) · [Tina](../children/tina.md) · [Luna](../children/luna.md) · [月度模板](../templates/monthly.md)

这里保存真实发生的经历、孩子的表达、家长的理解和月度回顾。目前尚无实际成长记录。

## 新增记录

1. 首次记录某个月时，将月度模板复制到 `journal/YYYY/YYYY-MM.md`，例如 `journal/2026/2026-10.md`，并将标题替换为实际年月。同一个月继续使用已有文件。
2. 在“随手记录”中复制一条记录格式，填写实际日期与参与人。只写有信息的项目，暂无信息的项目可以删除或留空。
3. 两人共同参与的事情写一次，分别记录 Tina 和 Luna 的表达或行为。家长理解与实际观察分开写。
4. 在下方月份索引添加指向该文件的链接。从本页链接时使用 `YYYY/YYYY-MM.md`；实际月度文件链接片单或孩子档案时，从 `../../watchlists/` 或 `../../children/` 起写。

模板里的占位内容不是经历。无需提前建好全年文件，也不必补齐没有记录的日期或月份。

## 月份索引

暂无月度文件。首次创建真实记录时，在这里添加对应月份的链接。

## 月底回顾

在同一个月度文件末尾分别回顾两个孩子：兴趣、变化、需要的支持，以及最多两个下一步；另写父母想调整的做法。有信息再写，资料不足时可以保留“暂无足够观察”。

回顾后，如有当前情况的变化，更新孩子档案的简短概括、日期和经历链接；如有资源使用反馈，在对应专题页更新状态和记录链接。未实际做过的建议继续作为建议保留。
