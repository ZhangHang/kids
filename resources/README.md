# 共享资源

[返回首页](../README.md) · [成长框架](../FRAMEWORK.md) · [实际体验记录](../journal/README.md)

收藏有理由尝试的资源，再根据孩子的实际反应决定是否继续。优先考虑内容价值和分别适合谁；普通话是观看偏好，家长可以寻找中文音频。

## 已有专题

| 专题 | 相关成长领域 | 分别适合谁／为什么收藏 | 当前使用情况 |
| --- | --- | --- | --- |
| [真实世界纪录片与科普节目](../watchlists/real-world.md) | 数学与科学、社会与真实世界 | Tina 可尝试完整的实验与解释；Luna 可选择直观的观察与日常事物主题；各节目详见片单 | 十部节目均为候选，尚无 Tina 或 Luna 的实际体验记录 |

有实际资源时，再增加图书、活动、场馆等专题。新专题在本页添加入口，具体资源和来源保存在专题页中。

## 每条资源记什么

- 名称、来源链接与查阅日期；中文译名不明确时保留原名。
- 相关成长领域，以及推荐的具体理由。
- 分别适合 Tina、Luna 怎样参与；年龄适配建议与已观察到的反应分开写。
- 两人的使用状态及更新日期；试过之后链接月度记录中的实际体验。

## 使用状态

| 状态 | 含义 |
| --- | --- |
| 候选 | 值得尝试，尚未确认孩子实际使用 |
| 试过 | 已有实际体验，暂未决定是否继续 |
| 继续 | 根据体验决定继续使用 |
| 暂放 | 暂时不安排，可简记原因，以后重新考虑 |

同一资源可对 Tina 和 Luna 保持不同状态。家长认可某部节目或助手推荐它，都不代表孩子已经看过。状态不必按固定顺序流转，未试过的候选也可以暂放。

具体观察只在月度记录中写一次。专题页保留简短结论和链接，避免与成长记录维护两份相同的反馈。
